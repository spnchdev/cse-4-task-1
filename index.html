1. Radiobutton


Елемент графічного інтерфейсу, що дозволяє користувачеві вибрати лише один варіант із попередньо заданого набору взаємовиключних параметрів.

2. Checkbox


Елемент графічного інтерфейсу, який дозволяє користувачеві зробити бінарний вибір (наприклад, увімкнено або вимкнено). Кілька прапорців можна вибирати незалежно один від одного.

3. Text input

Базовий елемент керування текстом, який дозволяє користувачеві вводити невеликий обсяг тексту, як правило, в один рядок.

4. Tabs

Вміст першої вкладки.
Вміст другої вкладки.

Навігаційний елемент для перемикання між різними поданнями або наборами вмісту в межах одного контексту.

5. Button

Елемент графічного інтерфейсу, який надає користувачеві простий спосіб ініціювати подію, наприклад, відправити форму або виконати команду.

6. Text label

Текст, який використовується для опису або ідентифікації іншого елемента керування або розділу інтерфейсу користувача.

7. Link

Це посилання

Посилання на дані, за яким користувач може перейти, натиснувши на нього. Зазвичай воно перенаправляє користувача на іншу сторінку або в інше місце на тій самій сторінці.

8. Tooltip

Наведіть на мене Це спливаюча підказка!

Коротке інформативне повідомлення, яке з'являється, коли користувач взаємодіє з елементом, зазвичай при наведенні на нього вказівника миші.

9. Dropdown list

Елемент керування, який дозволяє користувачеві вибрати одне значення зі списку. У неактивному стані відображає одне значення. При активації розкриває список доступних значень.

10. Data grid

2 Марія 25

Елемент керування у вигляді таблиці, який відображає дані в рядках і стовпцях. Використовується для систематизованого подання структурованої інформації.
